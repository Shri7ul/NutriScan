# 2026-10-27

## NutriScan v1 milestone implemented (empty repo → working Android app)

Workspace started as README + LICENSE + bare IntelliJ module (JDK 21) — no Gradle, no Android
sources. Built the full project from scratch and verified on an emulator.

Delivered:
- Gradle scaffold (Gradle 8.13 wrapper, AGP 8.13.2, Kotlin 2.3.0, version catalog, compileSdk 36,
  minSdk 24).
- Data layer: OFF v3 DTOs, Retrofit API, OkHttp (UA + timeouts), repository with LRU cache and
  in-flight de-duplication, typed `ProductError`.
- UI: home (language toggle, scan CTA, manual entry, recent scans), scanner (CameraX + bundled
  ML Kit, torch, permission states, debounce), details (nutrition/ingredients/allergens/missing
  markers, rescan). EN + BN strings, per-app locales.
- Tests: 23 JVM tests (parsing against a real captured payload, 404/429/5xx/malformed/timeout/
  offline, cache + de-dupe, barcode validation) and 1 instrumented test for the bundled model.

Results: assembleDebug, testDebugUnitTest, lintDebug, assembleRelease all pass; app verified on an
API 36 emulator (live Nutella lookup, not-found, offline error + retry, Bangla toggle, camera
preview, barcode decode in airplane mode).

Bugs found and fixed during verification: malformed JSON misclassified as Offline (Gson throws
IOException subclasses), test asset lookup needed the instrumentation context.
